# 🍎 Яблокат

![Яблокат](YABLOKAT/android-chrome-192x192.png)

## Что это за игра?

**Яблокат** — это увлекательная настольная игра для двух игроков, идеально подходящая для игры на скучных уроках! Вам понадобится всего **2 яблока** и стол с краем. Цель игры — набрать **меньше всего очков**, запуская яблоко так, чтобы оно прошло по полукругу и коснулось стоячего яблока.

## 🎮 Как играть?

### Что нужно для игры:
- **2 яблока** (одно для катания, одно статичное)
- **Стол с краем**
- **Два игрока**

### Подготовка:

1. Поставьте одно яблоко рядом со стеной на расстоянии **одного яблока + 2 фаланги пальцев** от края стола (это для самого сложного уровня "Яблокатер")
2. Чем легче уровень, тем **больше расстояние** между яблоками:
   - **Яблокатер** (самый сложный): 1 яблоко + 2 фаланги
   - **Хакер**: больше расстояние
   - **Профи**: еще больше
   - **Новичок** (самый легкий): максимальное расстояние

### Правила игры:

1. **Первый игрок** берет яблоко и пытается его **закрутить**, чтобы оно прошло траекторию по **полукругу**, не задев при этом:
   - Край стола
   - Статичное яблоко (до финального касания)

2. **Начисление очков:**
   - **1 очко** — яблоко коснулось стоячего яблока и дошло до цели (идеальный бросок)
   - **2 очка** — яблоко коснулось края стола и дошло до цели
   - **2 очка** — яблоко коснулось стоячего яблока **два раза** (даже если первый раз было 1 очко)
   - **3 очка** — игрок закрутил яблоко так, что оно не прошло и отлетело не туда (промах)

3. Игроки ходят **по очереди**, начисляя очки за каждый бросок.

4. Игра продолжается, **пока не надоест**.

5. **Победитель** — игрок с **меньшим количеством очков**!

## 🎯 Цель игры

Цель игры — набрать **меньше всего очков**. Чем точнее ваш бросок, тем меньше очков вы получите. Идеальный бросок — это когда яблоко проходит по полукругу и касается стоячего яблока только один раз, получая всего 1 очко.

- Выбирать уровень сложности

## 🚀 Установка

1. Загрузите файлы на хостинг
2. Создайте базу данных MySQL
3. Импортируйте `database/schema.sql`
4. Настройте `config/database.php` с вашими данными
5. Готово!

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP 7.4+
- **База данных**: MySQL 8.0
- **Веб-сервер**: Apache

## Настройка базы данных

Реальный файл `YABLOKAT/config/database.php` должен оставаться локальным. Для настройки используйте `YABLOKAT/config/database.example.php`.

1. Скопируйте `YABLOKAT/config/database.example.php` в `YABLOKAT/config/database.php`.
2. Заполните параметры подключения к MySQL.
3. Не коммитьте `YABLOKAT/config/database.php`.
